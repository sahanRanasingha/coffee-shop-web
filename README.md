# Coffee Shop Web

A modern, responsive landing page for a coffee shop built with plain HTML, CSS, and JavaScript. The site highlights menus, products, reviews, a contact form, and blog cards with smooth UI interactions.

## Features
- Responsive navigation with mobile menu toggle
- Search and cart panels with interactive controls
- Menu, products, and review sections with card layouts
- Contact form layout with embedded shop image
- Blog teaser grid and social links

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (CDN)

## Getting Started
1. Clone or download this repository.
2. Open `index.html` directly in your browser.

Optional local server (recommended for asset loading consistency):
- Use any static server (e.g., VS Code Live Server, `python -m http.server`, etc.).

## Project Structure
```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
```

## Customization
- Update content and section text in `index.html`.
- Adjust styling in `css/style.css`.
- Modify interactivity in `js/script.js`.
- Replace assets in `images/` as needed.
